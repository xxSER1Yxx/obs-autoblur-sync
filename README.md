# OBS AutoBlur Sync

Программа для автоматического наложения блюра в OBS Studio по таймингам с сайтов. Создана специально для стримеров на Twitch, чтобы избежать нарушений правил площадки.

## Особенности
* 🪟 Удобный графический интерфейс (.exe).
* 🗄️ Легкая локальная база данных с поддержкой мультиязычного поиска.
* ⚡ Автоматическая синхронизация с таймкодом плеера через OBS WebSocket.

## Установка
1. Скачайте готовый `.exe` файл из раздела [Releases](https://github.com/xxSER1Yxx/obs-autoblur-sync/releases).
